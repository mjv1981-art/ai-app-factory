# AI Factory regression baseline

The original counter example is preserved: initial count zero, increments of two, Shift-click
reset, and Reset button. Its existing Windows Chromium golden screenshot is unchanged.

Factory journeys: authenticated single-owner access; existing-project discovery and baseline
approval; private new-project planning and creation; request and revision-bound approval;
cloud job dispatch and cancellation; visible failed/incomplete evidence; token reservations
and reported usage; project knowledge by commit; isolated previews; draft PR and exact-commit CI;
human-owned merge.

Automation evidence is partitioned: real existing browser regression, real Factory UI against
a deterministic API/database fixture, orchestration tests with stubbed external services,
and live hosted acceptance. Passing one category does not establish another.

Preserve contract path authorization, owner isolation, secret isolation and test/baseline
protection. Never label unknown usage as zero or an unconfigured service as connected.

## CHANGE-005 guided workspace regression

- Distinct start actions; baseline/access/approval prerequisites are visible and enforced.
- Each run exposes its objective, stage, responsibility and next action; status is not a button.
- Stage trails reflect the actual profile and recorded evidence, including repair and missing history.
- Poll failure/stale heartbeat retains data, marks activity unconfirmed and never dispatches work.
- Reported, reserved and uncertain usage and known/unknown costs remain distinct.
- Safe clarification preserves original evidence and creates one linked fresh plan requiring approval.
- Superseded approval, stale base, cross-owner recovery and concurrent retry/replan are rejected.
- Duplicate access confirmation cannot reset a claimed worker; only the current claim can acknowledge cancellation.
- Lost publication replies and existing changed run branches cannot inherit prior candidate certification.
- Actual PR head and required CI gate readiness; merged/closed paths and post-merge baseline differ.
- Proposed and historical knowledge stays distinct from the accepted current baseline.
- Native keyboard, scoped busy feedback, preview/CSRF isolation and sign-out stay usable.
- Confirmed active animation/color, pause motion and reduced motion preserve accounting and execution.
- Both themes fit 320, 390, 736 and 1024 CSS pixels without document overflow.

The original seven Factory browser journeys retain their behavioral assertions; eleven
additional guided-workspace journeys cover the redesign. Original counter assertions and
Windows golden images remain unchanged. Hosted acceptance is recorded separately.
